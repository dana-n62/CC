## Description
This project is designed to develop your competency in several key areas of systems programming and computer graphics:
**Technical Skills:** <br>
The primary goal is to introduce you to graphics programming fundamentals including window management, event handling, image rendering, and sprite manipulation. You'll learn how the MiniLibX library interfaces with the X Window System to create visual applications.<br>
**Algorithmic Thinking:** <br>
The map validation component requires implementing pathfinding algorithms (likely flood fill or BFS) to verify that a valid path exists between the player, all collectibles, and the exit. This reinforces your understanding of graph traversal. <br>
**Software Architecture:** <br>
Managing game state, separating concerns between rendering, input handling, and game logic forces you to think about code organization in ways that simple algorithmic projects don't. <br>
**Memory Management:** <br>
Graphics programming with textures and images introduces new memory management challenges. Every texture loaded must be properly freed, and the cleanup sequence matters. <br>
